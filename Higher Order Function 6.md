# Higher Order Function 6

Fork this repository and solve the following problem.
---

Create a function parent which accepts a callback as a parameter and num as another parameter, you are tasked with invoking this callback with the digit num as the argument of this callback. Finally, return its result from the parent function.

## Input
1st line input take custom callback function in oneline.  
2nd line take a input as a number.

## Output
result of the callback function invoked with num and return final output.
