# Count the Number of Students Who Passed

Fork this repository and solve the following problem.
---

At Rishihood University, the grading system needs to determine how many students have passed an exam. A student is considered to have passed if their score is 40 or above.

Write a function countPassingStudents that:

Accepts multiple student scores as input.  
Returns the total number of students who passed.

## Input
A series of space-separated integers, representing student scores.
