# Getting from Object in JavaScript - CRUD-2

Fork this repository and solve the following problem.
---

You are given a JSON object as a string and a key. Your task is to fetch the value associated with the given key in the JSON object and return the value.

Constraints:

The key will always be present in the JSON object.  
The JSON object will have at most 100 keys.  
The JSON object and key will not contain nested objects or arrays.  
The value of the key will always be a string.

## Input
A single line containing:  
A JSON object as a string, A key (string) whose value needs to be fetched.

## Output
the value of the given key.
