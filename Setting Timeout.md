# Setting Timeout

Fork this repository and solve the following problem.
---

You are required to implement a function named logAfterDelay that takes two arguments:

message (a string)

delay (a number representing time in seconds)

The function should use setTimeout to log the value of message to the console after the specified delay (in seconds).

## Input
This is a functional problem in JS, you don't need to take any input. You need to just complete the function with the given requirements
