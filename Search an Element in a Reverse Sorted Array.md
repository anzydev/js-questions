# Search an Element in a Reverse Sorted Array

Fork this repository and solve the following problem.
---

Given a reverse sorted array of integers nums (i.e., sorted in strictly decreasing order) and an integer target, return the index of target in the array.

If target is not present, return -1.

Note: Since the test cases are executed multiple times, using a linear search leads to a Time Limit Exceeded (TLE) error. Therefore, the problem must be solved using an O(log n) time complexity approach.

## Input

User Task  
Since this is a functional problem you don't have to input anything, your task is to complete the function isPresent(), which takes three parameters as input, those are:  

Custum Input:  
The first line of input contains an integer T, the number of test cases.  

For each test case:  
The next line contains two integers separated by a space — the number of array elements n and the value target to search for.  

The following line contains n space-separated integers representing the array elements.

## Output
If the target is present in nums return its index else return -1.
